This is a simple text-based Hangman game developed using Python. The player tries to guess a hidden word one letter at a time. For each incorrect guess, the player loses one chance. The game ends when the player successfully guesses the word or uses all available attempts.

Features
Randomly selects a word from a predefined list.
Allows the player to guess one letter at a time.
Displays correctly guessed letters and hidden letters.
Limits incorrect guesses to 6 attempts.
Provides win or lose messages at the end of the game.
